Tableau Web Integration Architecture
Embedding Tableau Public & Desktop Visualizations into Modern Web Applications

SkillWallet's Web Integration module requires publishing the F1 Race Intelligence intelligence suite and embedding it into corporate intranets, media portals, or team strategy consoles. Below is the production integration blueprint utilizing the Tableau Embedding API v3.

Production Tableau Embedding API v3 Snippet:

<!-- Include Tableau Embedding API v3 Library --> <script type="module" src="https://public.tableau.com/javascripts/api/tableau.embedding.3.latest.min.js"></script> <!-- Embedded Tableau Visualization Web Component --> <tableau-viz id="f1RaceIntelligenceViz" src="https://public.tableau.com/views/Formula1RaceIntelligenceDashboardStory/Dashboard1-TeamStrategy" toolbar="bottom" device="desktop" hide-tabs="false" width="100%" height="900px"> </tableau-viz> <script type="module"> const viz = document.getElementById("f1RaceIntelligenceViz"); viz.addEventListener("firstinteractive", () => { console.log("Tableau F1 Race Intelligence Dashboard Ready!"); }); </script>

Hyper Extract Integration

The web layer connects to pre-aggregated extracts generated by preprocess_f1_data.py. This achieves sub-second response times even when users toggle multi-season filters.

Bi-directional Filter Passing

Using the Tableau JavaScript API, parameters like Year and Constructor can be dynamically passed via URL query strings or parent frame messages.

Responsive Breakpoints

Dashboards automatically switch layout modes between desktop (1400×900) and tablet/mobile viewports to serve both pit-wall engineers and mobile journalists.
